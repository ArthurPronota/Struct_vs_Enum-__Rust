# Struct vs Enum в Rust

## Краткий ответ

| | **Struct** | **Enum** |
|---|---|---|
| Что это | **Произведение** типов | **Сумма** типов |
| Активных полей | **Все** одновременно | **Ровно один** вариант |
| Аналог в математике | `A × B × C` | `A + B + C` |
| Когда использовать | Все данные **вместе** | **Один из** нескольких вариантов |

**Ключевое различие:**

- **Struct** — «**И** это, **И** то» (`и`).
- **Enum** — «**ИЛИ** это, **ИЛИ** то» (`или`).

## Struct — произведение типов

```rust
struct Rect {
    w: f64,
    h: f64,
}
```

**`Rect`** содержит **оба** поля **одновременно**: и `w`, и `h`.

**Математически:** `Rect = f64 × f64` — **декартово произведение**.

### Все поля присутствуют

```rust
let r = Rect { w: 10.0, h: 20.0 };
println!("{} × {}", r.w, r.h);   // оба поля доступны
```

## Enum — сумма типов

```rust
enum Shape {
    Circle(f64),
    Rect { w: f64, h: f64 },
}
```

**`Shape`** в **любой момент** — **либо** `Circle`, **либо** `Rect`. **Не оба** одновременно.

**Математически:** `Shape = f64 + (f64 × f64)` — **сумма** типов.

### Ровно один вариант активен

```rust
let mut sh = Shape::Circle(10.0);
// sh — Circle, Rect недоступен

sh = Shape::Rect { w: 15.0, h: 20.0 };
// sh — Rect, Circle недоступен
```

## Разбор примера

```rust
enum Shape {
    Circle(f64),
    Rect { w: f64, h: f64 },
}
```

### Варианты

- **`Circle(f64)`** — **tuple-вариант** с одним полем `f64`.
- **`Rect { w: f64, h: f64 }`** — **struct-вариант** с двумя полями.

### Функция `area`

```rust
fn area(s: &Shape) -> f64 {
    match s {
        Shape::Circle(r) => std::f64::consts::PI * r * r,
        Shape::Rect { w, h } => w * h,
    }
}
```

**`match`** — **обязателен** для enum:

- **все** варианты должны быть **покрыты**;
- компилятор **не даст** забыть вариант;
- при **добавлении** нового варианта — **ошибка** компиляции → **безопасность**.

### Использование

```rust
fn main() {
    let mut sh = Shape::Circle(10.0);

    println!("Circle: {}", area(&sh));   // 314.159...

    sh = Shape::Rect { w: 15.0, h: 20.0 };
    println!("Rect: {}", area(&sh));     // 300
}
```

- **`sh`** — **либо** `Circle`, **либо** `Rect`.
- **`area`** работает с **любым** вариантом через `match`.

## Память: как хранится enum

Enum занимает **размер самого большого варианта** + **дискриминант** (тег, указывающий активный вариант).

### Пример

```rust
enum Shape {
    Circle(f64),              // 8 байт
    Rect { w: f64, h: f64 },  // 16 байт
}
```

**Размер `Shape`:**

```
max(8, 16) + дискриминант = 16 + 8 = 24 байта
```

**Дискриминант** — число, указывающее **активный** вариант (0 = Circle, 1 = Rect).

### Niche optimization

Компилятор **умеет ужимать** представление, если есть **niche** (неиспользуемое значение):

```rust
Option<&T>
```

- **`&T`** — **не может** быть `null`.
- **`null`** — **свободное** значение → **niche**.
- **`Option<&T>`** использует `null` для `None` → **размер = размер `&T`**.

**Пример:**

```rust
use std::mem::size_of;

println!("{}", size_of::<&i32>());              // 8
println!("{}", size_of::<Option<&i32>>());      // 8 — не 16!
println!("{}", size_of::<Option<Box<i32>>>());  // 8
```

**Экономия памяти** — **бесплатно**.

## Struct vs Enum: сравнение

| Аспект | Struct | Enum |
|---|---|---|
| **Тип** | Произведение | Сумма |
| **Активных полей** | Все | Ровно одно |
| **Размер** | Сумма всех полей | Максимум из вариантов |
| **Доступ** | `.field` | `match` |
| **Комбинация** | `A × B` | `A + B` |
| **Пример** | `Point { x, y }` | `Option<T>`, `Result<T, E>` |

## Пример: struct + enum вместе

**Struct** — **данные**:

```rust
struct Point {
    x: f64,
    y: f64,
}
```

**Enum** — **варианты**:

```rust
enum Shape {
    Circle(Point, f64),           // центр + радиус
    Rect(Point, Point),            // два угла
    Triangle(Point, Point, Point), // три вершины
}
```

**Комбинация** — **мощная** модель.

## Классические enum в Rust

### `Option<T>`

```rust
enum Option<T> {
    Some(T),
    None,
}
```

- **Либо** значение, **либо** ничего.
- Замена `null`.

### `Result<T, E>`

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

- **Либо** успех, **либо** ошибка.

### `Shape` (ваш пример)

```rust
enum Shape {
    Circle(f64),
    Rect { w: f64, h: f64 },
}
```

- **Либо** круг, **либо** прямоугольник.

## Компилятор и `match`

### Исчерпывающий `match`

```rust
match s {
    Shape::Circle(r) => ...,
    Shape::Rect { w, h } => ...,
}
```

- **Все** варианты **покрыты** → ✅.
- **Компилятор** проверил.

### Забыли вариант

```rust
match s {
    Shape::Circle(r) => ...,
    // ❌ Забыли Rect
}
```

**Ошибка:**

```
error[E0004]: non-exhaustive patterns: `Shape::Rect { .. }` not covered
```

**Плюс:** при **добавлении** нового варианта — **все** `match` **сломаются** → **компилятор укажет** все места.

## `struct` vs `enum`: когда что

### Используйте `struct`

- Все данные **присутствуют** одновременно.
- **Комбинация** полей.
- **Примеры:** `Point`, `User`, `Config`, `Rect`.

### Используйте `enum`

- **Один из** нескольких вариантов.
- **Разные** наборы данных для каждого случая.
- **Примеры:** `Option`, `Result`, `Shape`, `Message`, `Event`.

## Сводная таблица

| | Struct | Enum |
|---|---|---|
| **Логика** | И | ИЛИ |
| **Математика** | Произведение | Сумма |
| **Активные поля** | Все | Ровно одно |
| **Размер** | Сумма полей | Максимум + тег |
| **Niche** | — | ✅ Экономия |
| **`match`** | Не нужен | **Обязателен** |
| **Расширение** | Ломает код | Компилятор укажет |

## Итог

- **Struct** — **произведение** типов: **все** поля **одновременно**.
- **Enum** — **сумма** типов: **ровно один** вариант **активен**.
- **Математически:** `struct = A × B`, `enum = A + B`.
- **Память:** enum = **max** вариант + **дискриминант**.
- **Niche optimization:** `Option<&T>` **не больше** `&T`.
- **`match`** — **обязателен** для enum, **исчерпывающий**.
- **Расширение enum** → **компилятор** укажет все `match`.
- **Классические enum:** `Option`, `Result`.
- **Комбинация** struct + enum — **мощная** модель данных.
- **Правило:** «И» → **struct**, «ИЛИ» → **enum**.
